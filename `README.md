# Banking Operations System

A comprehensive banking operations management system built with FastAPI (backend) and Next.js (frontend).

## Features

- **Customer Management**: Complete CRUD operations for customer data
- **Facility Management**: Loan, overdraft, LC/LG facility tracking
- **Dashboard Analytics**: Real-time statistics and insights
- **User Authentication**: Secure JWT-based authentication
- **Role-based Access**: Admin and user role management
- **Advanced Search**: Filter and search across all entities
- **Audit Trail**: Track all changes and operations

## Tech Stack

### Backend
- **FastAPI**: Modern Python web framework
- **SQLAlchemy**: ORM with async support
- **PostgreSQL**: Primary database
- **JWT**: Authentication tokens
- **Pydantic**: Data validation
- **Alembic**: Database migrations

### Frontend
- **Next.js 14**: React framework with App Router
- **TypeScript**: Type safety
- **Tailwind CSS**: Utility-first CSS
- **Axios**: HTTP client
- **React Hot Toast**: Notifications

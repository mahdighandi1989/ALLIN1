# قابلیتِ تنظیم‌نشده پیش از کلیک می‌گوید که تنظیم‌نشده است

## 🎯 چالش / Challenge

دکمهٔ «ایمیلِ ارسال‌نشده‌ها» همیشه فعال بود. روی سروری که SMTP ندارد، کاربر
می‌زد و پیامِ انگلیسیِ فنیِ «SMTP is not configured (set SMTP_HOST / …)» را می‌دید —
متنی که برای مدیرِ سرور نوشته شده بود، نه برای کاربری که فقط می‌خواست یادداشتش برسد.
همان صفحه حذفِ یادداشت را هم تا برگشتنِ پاسخِ سرور منتظر می‌ماند؛ روی نمونهٔ
سردِ سرور چند ثانیه طول می‌کشید و کاربر فکر می‌کرد کار نمی‌کند.

## 💡 راه‌حل / Solution

۱. **سرور وضعیتِ آمادگی را همراهِ فهرست بدهد** (`email_ready`)؛ UI پیش از کلیک
   دکمه را غیرفعال و دلیل را (فارسی، با نامِ دقیقِ چیزی که باید تنظیم شود) نشان بدهد.
۲. **خطای ۴۰۰ هم باید عملی باشد:** چه چیزی تنظیم نیست، چه کسی باید تنظیمش کند،
   و «داده‌ات از دست نرفت».
۳. **عملیاتِ محلی (حذف) خوش‌بینانه** باشد: ردیف همان لحظه برود، و فقط اگر سرور رد کرد
   سرِ جایش برگردد (rollback) و خطا بیاید.

## ⚠️ نکات حیاتی / Pitfalls

- غیرفعال‌کردنِ دکمه بدونِ گفتنِ دلیل، «دکمهٔ خراب» می‌سازد؛ همیشه یک خط توضیح کنارش.
- جایگزینِ «ارسال از کانالِ دیگر» (مثلاً تلگرامِ مشترک) برای دادهٔ **خصوصیِ هر کاربر**
  نشت است؛ بی‌اجازهٔ مالک نساز.
